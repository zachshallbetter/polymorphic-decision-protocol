# Pre-deposit readiness checklist

## Research integrity
- [x] Scope and claims are limited to a Type II protocol analysis.
- [x] No empirical results or validated performance claim is reported.
- [x] Private records and transcripts are excluded.
- [ ] Independent design/measurement review received and disposition recorded.
- [ ] Independent AI-evaluation/protocol-methods review received and disposition recorded.
- [ ] Author confirms CRediT roles, funding status, and any additional competing-interest declarations.
- [ ] Human author verifies all claims, mathematics, code status, and citations.

## Package and manuscript
- [x] RDP/RPP structure decision is documented.
- [x] Separate MIT software and CC BY 4.0 paper package metadata are prepared.
- [x] Markdown/PDF/LaTeX compile and parity inspected.
- [x] Source register completed and bibliographic records compared against primary sources during preparation.
- [ ] Human author performs final citation and DOI/version verification before deposit.
- [x] Exact file manifest reviewed for private data and unrelated files.
- [x] Checksums generated from final release files and independently verified.
- [ ] Current Zenodo schema and license identifier confirmed by the human depositor.

## Publication gate
- [ ] Both independent reviews complete; manuscript dispositions recorded.
- [ ] Paper DOI assigned by human deposit; never prefilled.
- [ ] Human owner approves and performs deposit and post-deposit verification.
- [ ] Author Research page deployed only after the above gates.
- [ ] At deposit, set the actual publication date and revalidate all Zenodo metadata against the live deposit form.
