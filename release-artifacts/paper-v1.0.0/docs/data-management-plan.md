# Data-management plan

## Data collected for this paper

No participant, model-interaction, or outcome data were collected for this manuscript. The private originating-case records and transcripts remain outside the repository and publication package. They are unavailable to independent reviewers under this work; their contents are not reproduced or treated as verified evidence.

## Storage and access

The manuscript package contains public protocol sources, public bibliographic metadata, and derived research records only. Do not copy private case records, account information, raw transcripts, or trade exports into this repository or a public archive. The author retains responsibility for any private record outside this package and its access controls.

## Future study data

Before Test 002, create a study-specific data plan covering model/provider terms, transcript capture, minimization, retention, access control, redaction, outcome provenance, and whether records may be shared. No future data-sharing license is declared here. Any future release of study data is contingent on rights, privacy, platform terms, and consent review. The current preprint contains no private source records.

## Preservation

Public manuscript, source, and metadata files use open text formats. SHA-256 checksums are generated only for the prepared package contents. Checksums do not establish provenance or validate source truth.
