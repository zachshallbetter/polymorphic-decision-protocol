# Limitations

1. The source protocol is a normative candidate, not an independently reviewed standard.
2. The prior-art search is preliminary and does not establish novelty.
3. The author-originating case is private, retrospective, and not independently inspectable; it is only development context.
4. Test 002 has not been executed. No efficacy, calibration, reliability, safety, or generality estimate is reported.
5. The categorical consensus weights are not empirically calibrated to residual error dependence.
6. The pressure-response classification lacks a validated coding manual and inter-rater evidence.
7. Repository tests cover functions and UI behavior, not end-to-end PDP operation or decision outcomes.
8. Funding and full CRediT declarations remain unconfirmed and should be resolved before an archival deposit or reviewed revision.
9. This public GitHub preprint has not received independent review or peer review; author verification of claims, mathematics, code, implementation status, and citations remains outstanding.
